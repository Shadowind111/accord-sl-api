# ACCORD-SL API (v11 reference)

Reference API specification for the ACCORD-SL two-tier GIST workflow.

- **Model release:** v11; **manuscript:** v13.
- **T1:** Blood3 + age; threshold 0.134.
- **T2:** 11 markers + age; threshold 0.237.
- Code and model weights: https://github.com/Shadowind111/accord-sl/releases/tag/v11.0.0

The deployed API is a research prototype, not a medical device. It must not be used for diagnosis, treatment, referral, or discharge decisions without local validation, governance approval, and regulatory review.

This repository is the public API contract/documentation repository. The model package and scoring code live in the main `accord-sl` repository/release.
